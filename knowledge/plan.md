# Plan

The assumed forward work of the project, cut into four lanes. The lanes are the sub-goals of [[knowledge/project]]; this document holds their order and what has to be true before each one starts. What has already happened is in [[knowledge/journal]], and the current writing state per chapter is in [[knowledge/state]].

## Lane order

1. **U1, repository and knowledge base.** The template is instantiated, the knowledge base carries the project description, this plan, the source register and the outline, the feeding sources are ingested into the Markdown layer, and the output layer holds the bilingual chapter skeleton. Running.
2. **U2, manuscript parts I to III.** Written from the lecture notes and the slide deck. Starts once U1 has left a checkable vault, because the chapter files and the topic maps are what the assertion work fills. Runs source by source through the full vertical pass, distillate, assertions, chapter, so a defect in the anchor mechanics shows up in one file rather than in all of them.
3. **U3, manuscript parts IV to VI.** Written from the Promptotyping paper, the Promptotyping document templates and the hands-on chains. Independent of U2 in its sources and dependent on it in its terminology, because the terms Part IV uses are introduced in Part II. Parts of it can run in parallel with U2 once the glossary carries the shared terms.
4. **U4, reading view on GitHub Pages.** Publishes the manuscript as a reading view. Needs at least one accepted chapter to have a subject, and it owns `docs/` and the repository settings, which no other lane touches.

## Before the writing lanes start

- The first production cycle runs vertically on one source, from the original through its Markdown representation, its distillate and one assertion to one written paragraph, before a second source is distilled. The procedure is in [[knowledge/operations]].
- The German parallel version is written after its English counterpart is accepted, so that both rest on the same assertion set and the mirror in the frontmatter stays identical.
- A source that no row of the feeding map names enters [[knowledge/sources]] before it is used.

## Open work

- Decide which dataset carries the worked example of Part VI.
