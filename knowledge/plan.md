# Plan

The assumed forward work of the project, cut into four lanes. The lanes are the sub-goals of [[knowledge/project]]; this document holds their order and what has to be true before each one starts. What has already happened is in [[knowledge/journal]], and the current writing state per chapter is in [[knowledge/state]].

## Working mode

By the author's decision of 2026-10-15 the book stays a side project. It grows through source-bound text modules written in this Grounded Vault when a concrete writing commission names them, and it carries no additional duty to document failed attempts or to record time. The DH Developer Skriptum merges into the book as a writing project. Its existing texts stay available as source material, its separate completion with pilot acceptance and its own milestone sequence are dropped, and the merge does not yet decide the adoption of any single statement or chapter, which needs a check first. Promptotyping stays a paper of its own and the Knowledge, Context and Agentic Engineering course a teaching system of its own. The decision is recorded in the project overview of the book in the author's Obsidian vault (`Projects/Eigenforschung/Applied Generative AI for Research/Project Overview Applied Generative AI for Research.md`, section Schreibauftrag und Zusammenführung).

## Lane order

1. **U1, repository and knowledge base.** The template is instantiated, the knowledge base carries the project description, this plan, the source register and the outline, the feeding sources are ingested into the Markdown layer, and the output layer holds the bilingual chapter skeleton. Done on 2026-08-22.
2. **U2, manuscript parts I to III.** Written from the lecture notes and the slide deck. Runs source by source through the full vertical pass, distillate, assertions, chapter, so a defect in the anchor mechanics shows up in one file rather than in all of them. All chapters of parts I to III exist as drafts in both languages since 2026-08-22; none is accepted by the author.
3. **U3, manuscript parts IV to VI.** Written from the Promptotyping paper, the Promptotyping document templates, which entered as one source for the set of seventeen templates as recorded in [[knowledge/journal#2026-08-22 — Parts IV to VI written from the paper and the template set]], and the hands-on chains. Dependent on U2 in its terminology, because the terms Part IV uses are introduced in Part II. All chapters of parts IV to VI exist as drafts in both languages since 2026-08-22; none is accepted by the author.
4. **U4, reading view on GitHub Pages.** Publishes the manuscript as a reading view and owns `docs/` and the repository settings, which no other lane touches. The plan required at least one accepted chapter first. The reading view was nevertheless built from the drafts and is served at `https://dhcraft.org/applied-generative-ai-for-research/` since 2026-08-22, which the author has to confirm or withdraw.

## Before the writing lanes start

- The first production cycle runs vertically on one source, from the original through its Markdown representation, its distillate and one assertion to one written paragraph, before a second source is distilled. The procedure is in [[knowledge/operations]].
- The German parallel version is written after its English counterpart is accepted, so that both rest on the same assertion set and the mirror in the frontmatter stays identical.
- A source that no row of the feeding map names enters [[knowledge/sources]] before it is used.
