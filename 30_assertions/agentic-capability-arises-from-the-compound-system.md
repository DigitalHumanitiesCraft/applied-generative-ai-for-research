# Agentic capability arises from the compound of model, harness and environment rather than from the model

## Statement

What a system can do follows from the model together with the runtime substrate that gives it context, tools, state and feedback, and from the environment in which it acts. Evaluating a model in isolation therefore measures something other than the capability a project actually has.

## Support

- [[20_distillates/documents/lecture-notes-en#^e6]] — states that agentic capability arises from the combined model, harness and environment system
- [[20_distillates/documents/lecture-notes-en#^e10]] — states that the effective system is a compound rather than a model in isolation
- [[20_distillates/documents/lecture-notes-en#^e110]] — gives the systems perspective in which software engineering capability arises from the combined system
