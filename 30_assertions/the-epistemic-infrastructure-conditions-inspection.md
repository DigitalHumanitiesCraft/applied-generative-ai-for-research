# Files, project knowledge, schemas, tests, provenance, outputs and decisions together form the infrastructure that makes an output inspectable

## Statement

No single component establishes whether a generated representation can be criticised, validated and accepted for a purpose. The arrangement does, and the question a project has to answer is therefore under which technical and epistemic conditions its outputs can be inspected, justified and used, including where subagents draw on schemas and scripts to check a generated encoding.
