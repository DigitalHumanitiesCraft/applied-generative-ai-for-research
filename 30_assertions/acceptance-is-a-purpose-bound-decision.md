# Acceptance is the responsible decision to adopt an identifiable state for a named purpose

## Statement

A technically verified artefact can be scholarly unsuitable and a scholarly interesting demonstrator can be unfit for publication. Acceptance therefore has to name the purpose it holds for, and without that binding it asserts more than the evidence carries.

## Support

- [[20_distillates/documents/lecture-notes-de#^s140]] — defines acceptance as the responsible decision on an identifiable project state for a named purpose
- [[20_distillates/documents/lecture-notes-de#^s141]] — gives the two cases in which verification and suitability come apart
- [[20_distillates/documents/lecture-notes-en#^e140]] — states that an explicit decision remains necessary after verification and validation
