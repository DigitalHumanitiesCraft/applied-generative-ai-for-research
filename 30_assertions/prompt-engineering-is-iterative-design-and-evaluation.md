# Prompt Engineering is the iterative design and evaluation of an input sequence for a defined model and task

## Statement

The work proceeds by changing content, structure or applied technique and assessing the result. The term is deliberately narrower than Context Engineering, because it addresses one concrete input sequence rather than the whole information environment of a longer working trajectory.
