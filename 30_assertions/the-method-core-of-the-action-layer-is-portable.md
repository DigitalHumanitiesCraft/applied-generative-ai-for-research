# The method core of the action layer is portable across coding agents, and only the tool block is exchanged

## Statement

The method core comprises knowledge-base routing, handoff processing, provenance rules, the rules of the checking layer, design principles, scope, and the hierarchy of truth. It is independent of the particular coding agent, so a change of agent exchanges the tool-specific block and leaves the core in place.
