# Iterative prompt engineering is an external search for an effective address into the learned repertoire

## Statement

A user varies the query and evaluates the resulting behaviour, which is a search conducted from outside the model. The engineering focus nevertheless shifts away from the isolated instruction, because effects depend on model, version, task, context and evaluation.
