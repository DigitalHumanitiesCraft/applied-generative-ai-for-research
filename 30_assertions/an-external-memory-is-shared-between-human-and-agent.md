# A folder of open text files is an external memory that a person and an agent read and write alike

## Statement

Notes held as plain text in an ordinary local folder stay on the machine in an open format without a server or an account. Such a holding organises individual and institutional knowledge, steers operative work and represents knowledge structures, and it is what an agent needs, because its context window is a bounded and volatile working memory while the folder is the long-term store.
