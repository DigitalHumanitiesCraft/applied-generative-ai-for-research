# The Semantic Web pursued the same agent vision by the reverse route, structuring the data instead of the language

## Statement

The vision of 2001 did not aim at machines understanding human language. Machine-understandable documents meant that a machine solves a well-defined problem on well-defined data, with humans structuring their data through ontologies and unique identifiers. Contemporary language models process unstructured text directly and reach the same goal without that infrastructure.
