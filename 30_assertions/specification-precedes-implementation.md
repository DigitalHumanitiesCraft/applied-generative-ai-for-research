# An explicit specification stands between exploratory discussion and implementation

## Statement

Developing requirements, user stories, data constraints, interfaces and verification criteria before substantial implementation reduces the tacit interpretation delegated to the agent and creates an object that can be reviewed before code exists. The same discipline appears in the working prompt, which asks for a conceptual approach and a compact plan first and requires the agent to ask about everything it cannot derive reliably instead of making silent assumptions.
