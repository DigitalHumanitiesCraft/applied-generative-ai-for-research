# Frontier models amplify work unevenly, according to how far it is digitally represented, executable and checkable

## Statement

Amplification is strongest where the relevant information is digitally represented, where actions can be executed through software and where the environment returns useful feedback. Because the effect also depends on existing expertise, accessible data, technical infrastructure and the ability to assess an output, the same system extends different practitioners by very different amounts.
