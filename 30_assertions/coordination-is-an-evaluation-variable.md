# Coordination is an explicit variable of evaluation wherever single-agent and multi-agent arrangements are compared

## Statement

Evaluations should record dependency structure, coordination overhead, error propagation, handover volume, persistent write targets, and the distribution of checking responsibilities when they compare single-agent and multi-agent arrangements, because coordination topology can affect overhead and error propagation.
