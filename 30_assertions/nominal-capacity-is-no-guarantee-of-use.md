# A large context window is no guarantee that everything inside it is used reliably

## Statement

Position, distraction and volume influence performance, and relevant information can be harder to find in long inputs when it stands between similar or contradictory content. Context Rot names the observed decline in retrieval and use as contexts grow longer, denser or more distracting, and it is no single settled mechanism, since position effects, distractors, conflicting information, obsolete intermediate state and the structure of the task can all contribute. Performance can therefore fall before the formal limit is reached.
