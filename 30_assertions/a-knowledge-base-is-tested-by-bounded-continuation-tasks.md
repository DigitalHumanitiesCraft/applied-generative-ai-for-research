# The practical sufficiency of a knowledge base is tested by having an independent contributor continue a bounded task

## Statement

Independent contributors are asked to explain the project, diagnose a selected discrepancy, or continue a delimited implementation task using the maintained documents and project resources. Observed difficulties are attributed, where possible, to documentary, technical, access-related, or competency-related limitations.
