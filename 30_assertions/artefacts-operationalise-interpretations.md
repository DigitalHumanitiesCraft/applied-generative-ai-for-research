# A functional artefact makes modelling decisions examinable in a way a schema cannot, because it shows how distinctions behave in use

## Statement

Digital Humanities scholarship has long treated prototypes, interfaces, and visualisations as forms through which interpretative claims and research possibilities can be explored rather than merely presented. Whereas a schema presents a model through formal notation, an interface shows how selected distinctions behave when data are entered, filtered, compared, and represented, and documented episodes exist in which project partners examined categories through such operations rather than through the formal definition alone.
