# A lightweight plain-text format exposes structure to humans and models and guarantees nothing about content

## Statement

Headings, lists, links, tables and code blocks make structure visible with little markup, the files are versionable line by line, referenceable and selectively includable in a working context. The format creates a shared surface on which people and agents work on the same holding, and it is not superior to richer formats where encoding standards, structured data formats, databases or schemas are required by their semantics or constraints.
