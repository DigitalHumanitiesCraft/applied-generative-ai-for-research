# A tool protocol solves an integration problem and decides nothing about relevance or reliability

## Statement

Standardising the connection between applications and tools lets one server expose a repository, a database or a validator to every client that speaks the protocol, which removes the need for a bespoke connector per pair. Whether a tool suits the task, whether its data are reliable and how its results are to be interpreted in the matter stay outside what the standard settles.
