# A controlled comparison showed that richer prompt metadata can introduce information into a transcription that is not visible in the image

## Statement

In an estate-corpus workflow, selected information from existing encoded records was inserted into the prompt supplied with each manuscript image, and the classification of the object determined which task-specific transcription prompt the model received. A controlled comparison then showed that richer metadata could introduce information from the prompt into a transcription even when that information was not visible in the image, and in the parallel library workflow model-generated document classifications were treated as provisional hypotheses rather than authoritative descriptions.
