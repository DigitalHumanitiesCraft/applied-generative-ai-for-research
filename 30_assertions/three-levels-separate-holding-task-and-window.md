# Project Knowledge Base, Working Context and context window are three levels that must not be collapsed

## Statement

The knowledge base preserves the persistent, inspectable and revisable holding, the working context is the information state assembled for a concrete task, and the window is the technical space in which that state is processed. General reports, guidelines for other source types, complete logs, superseded schema versions and obsolete attempts belong in the holding and not in the working context of a single task, and knowledge documents need not be loaded in full for every task.
