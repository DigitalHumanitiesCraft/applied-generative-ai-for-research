# Agent instruction documents translate maintained project knowledge into imperatives and carry no knowledge of their own

## Statement

Agent instruction documents define the technical baseline, working procedures, constraints, and checks governing an agent's work. In the template set the action document lies in the repository root rather than in the knowledge folder, routes to the declarative knowledge base, and translates it into imperatives, and the same composition is used for the aesthetic layer, where the declarative design document supplies the values and the action layer states the rules. Keeping these comparatively volatile instructions separate from more stable accounts of the data and the scholarly purpose prevents temporary implementation directives from silently altering the project's maintained understanding, and it prevents a knowledge document from changing its analytical type.
