# An interface can present uncertainty as settled and thereby manufacture a certainty the data do not carry

## Statement

The questions to ask of a running artefact are whether uncertainties appear as uncertainties, whether the surface produces false unambiguity, which modelling problems become visible only there and which documents must be revised as a result. Each stage from source through transcription, data model and transformation to display carries decisions about which differences become visible, editable and interpretable, and an agent cannot take over responsibility for them.
