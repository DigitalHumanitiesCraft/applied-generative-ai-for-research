# An error entering early is carried through the whole trajectory by technically plausible later steps

## Statement

With growing task duration the number of places at which an error can enter later steps rises alongside the possible output. An agent that reads an outdated guideline can generate an unsuitable pattern, transform it and adapt everything downstream to the wrong structure, and each single step looks correct while the original defect propagates.
