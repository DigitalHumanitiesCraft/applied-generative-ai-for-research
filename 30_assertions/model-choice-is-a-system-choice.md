# Choosing a model is choosing a system, not reading a benchmark

## Statement

Systems differ in capability, modalities, inference cost, latency, openness, deployment options, context capacity, tool use and the harnesses through which they can operate. A choice made on benchmark performance alone silently fixes all the other properties.

## Support

- [[20_distillates/documents/lecture-notes-en#^e9]] — lists the dimensions along which systems differ and warns against reduction to benchmark performance
