# Agent-to-agent protocols address a second interaction surface, collaboration among peers

## Statement

Such a standard supports discovery, task management and the exchange of results without requiring an agent to expose its memory, tools or implementation, and it is complementary to a tool protocol rather than a replacement for one. The methodological questions stay open regardless, which agent is responsible for what, which information is handed over, how conflicts become visible and who decides when results contradict one another.
