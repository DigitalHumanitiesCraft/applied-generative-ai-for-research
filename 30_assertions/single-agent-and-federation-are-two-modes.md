# A single tool-supported agent and an orchestrated federation are two modes of operation rather than two categories

## Statement

In the narrower sense an agent is a modular system driven by a language model for delimited tasks, with tool access, memory and planning around the model. An orchestrated federation adds collaboration, dynamic task decomposition, persistent memory and coordinated autonomy, and it differs by architecture rather than by degree of autonomy. The same tool shows both modes, acting as one agent in a simple run and as a federation once it delegates to several coordinated instances.
