# Software operationalises only those distinctions that have been encoded in structures its representational model can process

## Statement

Scholarly work with digital research data is mediated by software, and a tool can process only what has been expressed in the structures its representational and operational model supports. The direction of that translation has ordinarily run from the project towards the tool, so researchers map their data and questions into the representations and operations that existing software provides.
