# An intermediate state has to be executable, assignable, checkable and small enough to locate a cause

## Statement

A useful increment can be run or inspected, belongs to a defined project state, can be checked against requirements and is small enough that the cause of an error can be reconstructed. Plans, decisions, check results and open questions belong in persistent project artefacts rather than in the chat history alone.
