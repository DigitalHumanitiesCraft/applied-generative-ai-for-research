# The charter document carries the identity and scope of a project and is not replaced by a public README

## Statement

The charter is the canonical carrier of what the project is, abstracted from concrete project overviews, and a public README may derive from it while referring back to the knowledge base. It carries for projects that process or produce a delimited material, that sit in an institutional, methodological, or technical context which is not self-explanatory, and that have defined functions whose description differs from the description of what is deliberately not provided.
