# A long run accumulates intermediate output that competes with what the current step needs

## Statement

Outputs, errors, tool results and earlier decisions gather, and in one undifferentiated context the agent can spend substantial effort navigating its own history. Stable knowledge can stay outside the transient conversation, relevant parts can be loaded when needed, and completed stages can leave compact artefacts that later stages consume instead of carrying every token forward.
