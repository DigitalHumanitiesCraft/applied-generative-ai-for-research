# A runnable, inspectable, and versioned artefact state is the basis for verification rather than an accepted iteration

## Statement

Implementation is provisionally sufficient when the current artefact state is runnable, inspectable, and identifiable through versioning, so that it can support verification and discussion with responsible contributors. That state is the basis from which purpose-specific verification and acceptance proceed.
