# Findings arise at several interacting but non-interchangeable levels, and each has to be attributed before it is written back

## Statement

The documented cases produced findings concerning the represented domain, source interpretation, research-data models, capture practices, transformations, interface representations, the organisation of agentic work, checking procedures, and the allocation of authority. Treating every observed problem as a defect in generated code would conceal the scholarly, technical, and organisational decisions through which the artefact was produced. Attributing a finding to the layer that produced it prevents limitations of the model from being concealed through interface logic while avoiding unnecessary changes to the domain model, and although an implemented artefact makes the effects of several layers visible together, responsible interpretation has to distinguish which layer produced the observed consequence.
