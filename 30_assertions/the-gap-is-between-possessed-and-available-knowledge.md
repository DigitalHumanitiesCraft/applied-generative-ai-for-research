# Knowledge Engineering starts from the gap between knowledge possessed and knowledge operationally available

## Statement

Experts rely on tacit distinctions, remembered decisions, local file structures, disciplinary conventions and experience that no one has represented. A model cannot use what remains in a person's memory and an agent cannot reconstruct conventions that were never written down, so the question is whether relevant knowledge has been externalised in a usable and revisable form.
