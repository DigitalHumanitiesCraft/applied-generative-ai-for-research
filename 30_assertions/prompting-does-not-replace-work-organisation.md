# A prompt does not replace project knowledge, resolved requirements, permissions, tests or validation

## Statement

Prompt Engineering makes a current task more precise and cannot on its own solve problems of knowledge and work organisation. Missing or inaccessible project knowledge, contradictory guidelines, unresolved requirements, an overloaded context, absent documentation, tool and permission management, technical tests and scholarly validation all lie outside what a formulation can reach.
