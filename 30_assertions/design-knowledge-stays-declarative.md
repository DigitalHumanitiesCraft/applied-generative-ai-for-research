# The design document records design stance, design system, interaction patterns, and visualisation logic as declarative knowledge

## Statement

The design document is read by a reviewer examining the design stance, by a designer working against it, and by a coding agent that needs the project's scale of values before it generates an interface. The socialisation of the agent on the aesthetic layer arises through composition with the action layer rather than through imperatives inside the design document itself.
