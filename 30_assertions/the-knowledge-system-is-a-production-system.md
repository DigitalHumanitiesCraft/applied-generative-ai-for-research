# The knowledge system serves the derivation of target artefacts rather than storage

## Statement

Curated and condensed knowledge documents are the input of the step that produces a concept, a proposal, a specification or a data model. The user story bridges the two activities, because it puts a requirement into a form that a person understands and an agent can use as context, and requirements arise from the relation among data, research questions and scholarly practices rather than from the data model alone.
