# A skill packages a reusable procedure and is loaded only when it becomes relevant

## Statement

It is a folder with an instruction file and optionally scripts, references and assets, and it holds procedural rather than descriptive knowledge. Only its name and description stay present at session start, the full instructions load when the skill becomes relevant, and further resources load later, which lets a system keep many specialised capabilities without injecting all of them into every task.
