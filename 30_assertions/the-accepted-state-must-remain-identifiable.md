# The accepted state must remain identifiable and reconstructable through a durable reference

## Statement

The relation on which acceptance rests has to remain recoverable through a repository release, an archived deposit, or another durable reference, without requiring a particular hosting platform or versioning scheme. A renewed implementation using another model, harness, or project state constitutes a new iteration rather than a silent reproduction of the earlier promptotype.
