# Atomisation and consolidation run in opposite directions towards the same goal

## Statement

Atomisation divides a monolithic record in which many separately referenceable concepts lie mixed into atomic documents, one concept each, while the original becomes a map that points to them. Consolidation merges several documents with redundant foundations and a fragmented presentation into one comprehensive document with the redundancy removed. Both serve the clean assignment of one concept to one unit.
