# A knowledge document is a condensation performed in advance that the model no longer has to make itself

## Statement

It is an atomic, structured knowledge unit distilled from raw material such as sources, experiences and data, and it is optimised as a context artefact for the collaboration between people and language models. In Context Engineering it functions as materialised context compression, which moves the reduction out of the run and into a maintained artefact.
