# A collection of files is not a knowledge base, and searching it does not produce a project understanding

## Statement

Knowledge in a project is distributed across guidelines, correspondence, examples and the experience of individuals, and long-standing participants supply the missing connections without noticing. An agent can search everything and still mix an old rule with a new one or generalise a single example into a convention, because existing local order is not yet a holding usable across a system.
