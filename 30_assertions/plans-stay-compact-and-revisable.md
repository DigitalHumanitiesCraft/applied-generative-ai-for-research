# A plan stays compact, checkable against the current state and revisable

## Statement

It should determine which sub-problems exist, which information is missing, which tools are needed, which checks are foreseen and in which order to proceed. An extensive plan drawn up before the holdings have been inspected creates false certainty, which makes planning before exploration a failure mode of its own.
