# The Latent Program Space account reads a model as a repertoire of learned transformations that prompts select and combine

## Statement

On this account an input acts partly as a signal that addresses learned computational structures rather than as a request answered from a store. A vector program is a distributed transformation implemented through high-dimensional representations and parameters, not a symbolic program held as a discrete object, and behaviours such as translating, summarising or classifying are recurring patterns arising from weights and the current activation course.
