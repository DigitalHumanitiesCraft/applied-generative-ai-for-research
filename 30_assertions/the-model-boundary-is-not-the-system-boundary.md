# Three information layers must be distinguished, and the boundary of the model is not the boundary of the system

## Statement

Learned representations in the parameters, retrievable information in external resources, and the information present in the current context are three different layers. A claim about what a system can know is therefore underdetermined as long as it names only the model.

- [[20_distillates/documents/lecture-notes-en#^e27]] — names the three layers of parameters, external resources and current context
