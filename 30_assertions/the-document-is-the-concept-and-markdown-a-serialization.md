# The knowledge document is a conceptual artefact and Markdown is one possible serialization of it

## Statement

The document is not bound to a file format. Plain text with light structure is used here because it is open, versionable, linkable and readable by people and by models alike.

## Support

- [[20_distillates/documents/lecture-notes-de#^s92]] — states that the document is a conceptual artefact and gives the reason for Markdown
- [[20_distillates/documents/lecture-notes-en#^e85]] — states the distinction between the concept and its serialization
- [[20_distillates/documents/slide-deck#^k27]] — lists the properties that make the format suitable
