# Knowledge document, instruction file, skill and prompt carry four different duties

## Statement

A knowledge document describes what is known about a subject, an instruction file fixes recurring rules for the work, a skill operationalises a reusable procedure, and a prompt formulates the current task. Not every piece of persistent information is a knowledge document, and assigning a statement to the wrong artefact makes it either invisible or permanently present.
