# As a task grows longer the object of design shifts from the wording of an instruction to the information state

## Statement

Complex work contains more relevant information than should enter a single prompt, because goals, documents, data, policies, requirements, examples, design decisions, previous findings, open questions and validation criteria matter without mattering at the same time. Context Engineering extends the design from the immediate instruction to the environment in which it is interpreted, covering what is available, how it is represented, in which order it appears, what can be retrieved and what is deliberately omitted.
