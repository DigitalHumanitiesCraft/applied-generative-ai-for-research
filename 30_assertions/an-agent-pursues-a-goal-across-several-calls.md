# An agent pursues a goal across several model and tool calls and adapts to what it observes

## Statement

An isolated call produces an output. An agent inspects its environment, selects an action, observes the result and updates its procedure, and the distinction does not require complete autonomy, since contemporary agents work inside human-defined goals, tools, permissions and stopping conditions. What matters is that the model participates in selecting and coordinating several actions.
