# Findings from implementation and checking have to be written back into the documents responsible for them

## Statement

They do not become project knowledge by being produced. They are inspected and, where warranted, returned into the maintained holding, which prevents relevant knowledge from remaining only in the chat, in the code or in the memory of individuals.

- [[20_distillates/documents/lecture-notes-de#^s146]] — states that implementation and checking produce knowledge that must be written back

- [[20_distillates/documents/lecture-notes-en#^e94]] — states that findings do not automatically become project knowledge and are written back where warranted
