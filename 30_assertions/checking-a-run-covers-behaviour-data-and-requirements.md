# Checking a generated artefact covers its behaviour, its data handling, the agreed requirements and the untouched sources

## Statement

The four questions are whether it runs, whether the data are read and displayed correctly, whether the agreed requirements are implemented and whether the source files have remained unchanged. The last of them is a property of the run rather than of the artefact.
