# The unit of assessment shifts from a single response to a whole trajectory

## Statement

An agentic system produces observations, intermediate decisions, tool calls, file modifications, execution results and subsequent actions, so reliability depends on the organisation of the complete sequence. Engineering that sequence is the object of the discipline rather than engineering an answer.
