# The ability to produce an artefact is not the ability to judge its correctness or adequacy

## Statement

An agent can inspect project resources, combine information, generate and execute code, process error messages and adapt to the observed state. None of that establishes whether the result is technically correct or scholarly adequate, so the challenge lies in organising the conditions under which results are produced, checked, revised and used for a named purpose.
