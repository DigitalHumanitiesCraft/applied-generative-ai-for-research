# Productive work with agentic systems follows from the interplay of knowledge, context, execution and checking rather than from a model or a prompt

## Statement

A single precisely worded instruction suffices for a bounded task and stops sufficing once a task spans several files, tools and decisions. The questions that then arise belong to different layers, the design of the current task, the persistent project knowledge, the selection of task-specific context and the control of multi-step execution.
