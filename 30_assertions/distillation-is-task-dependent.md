# The same material has to be distilled differently for different tasks

## Statement

A general introduction, an implementation specification and a verification task need different representations of one body of knowledge, and every reduction decides which distinctions remain available for the work that follows. Distillation is therefore epistemically consequential rather than a matter of convenience.
