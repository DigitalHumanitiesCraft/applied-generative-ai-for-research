# A research artefact can participate in forming the model, capture practice, and requirements from which it is developed

## Statement

In a project whose data model and requirements were still developing, data capture and interface functionality were developed alongside the model, so that implementation became a means of examining and revising the emerging model in practice. This prospective function holds on the condition that the consequences disclosed through use are interpreted, documented, and incorporated into maintained project knowledge.
