# The integration document holds the currently valid contract at a project boundary, with one declared source of truth

## Statement

The integration document carries exchange format, responsibilities, and acceptance criteria at the boundary between projects, and it is delimited against the architecture document, which describes the internal structure of one's own project, against the process inbox, which carries incoming deltas until they are integrated or discarded, and against the provenance record, which evidences the completed transition. Where both sides describe the same contract, exactly one side is declared the source of truth and both reference each other, because one-sided linking was the consistency defect found when the templates were extracted from practice.
