# Mapping research data into an existing tool confines subsequent work to the distinctions and operations that tool provides

## Statement

Mapping data into an existing tool may require less implementation effort than developing a project-specific artefact, and it also limits what can be asked afterwards to the distinctions, operations, and forms of interaction the tool offers.
