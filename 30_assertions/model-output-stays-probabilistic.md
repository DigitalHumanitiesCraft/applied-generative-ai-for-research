# The output of a language model stays probabilistic, so the same input can produce different results

## Statement

Repetition of the same prompt can yield different results, and a plausible formulation is therefore not a reconstructed fact. The variation is a property of the procedure rather than a defect of a particular run.

## Support

- [[20_distillates/documents/lecture-notes-de#^s15]] — states the variation across runs and denies the inference from plausibility to fact
