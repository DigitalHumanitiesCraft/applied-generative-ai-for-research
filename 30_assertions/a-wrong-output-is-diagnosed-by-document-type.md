# The type of a wrong output names the document that has to be revised

## Statement

A formally wrong output, a break in style, or an ignored prohibition is diagnosed in the action document, while a substantively wrong output is diagnosed in the knowledge documents and is not patched in the action layer. The same question decides how a document is typed in the first place, so a rule set that binds how something is built counts as an action document even where it is written as reasoned rules rather than as imperatives.
