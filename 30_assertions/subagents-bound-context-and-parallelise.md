# A subagent bounds a context and makes parallel work possible without removing the duty to validate

## Statement

A delegated instance works on a bounded part of a task in its own fresh context, inspects a defined subset of resources and returns a compact result, which protects the parent context from volumes of intermediate material and allows independent checks to run at once. The pattern carries no formal standard and appears in nearly identical form across agent systems, and every delegated instance needs a clear assignment, bounded context, a defined return format and rules for uncertainty.
