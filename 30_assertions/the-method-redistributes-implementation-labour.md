# Promptotyping redistributes implementation labour rather than eliminating it, and the redistribution has not been measured

## Statement

An agent may produce an initial functional artefact rapidly, while domain specialists still specify requirements, examine outputs, interpret discrepancies, and determine what can be accepted, and Research Software Engineers may later refactor the implementation for dependable operation. Evaluation must therefore distinguish effort that is reduced from effort that is transferred, newly created, or deferred, including the work of maintaining project knowledge, coordinating and examining agentic work, and preserving an intelligible and verifiable project state. The combined burden of these activities has not been measured systematically in the documented cases.
